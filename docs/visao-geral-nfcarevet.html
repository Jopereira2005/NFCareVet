Experiência Simples & Intuitiva

Como Funciona na Rotina do Hospital

A tecnologia foi desenhada para não exigir treinamento complexo: é tão simples quanto pagar por aproximação.

1

Admissão & Coleira

O pet dá entrada na clínica. A recepção cadastra o tutor e coloca uma coleira NFC higienizada no pescoço do animal, associando à baia livre.

💡 Como colocar uma pulseira de identificação em um paciente humano no hospital.
2

Prescrição Médica

O médico veterinário prescreve os medicamentos (antibióticos, anti-inflamatórios, soro) e os horários no painel web do hospital.

💡 O sistema cria a agenda de tarefas do turno automaticamente.
3

Checagem Beira-Leito

O enfermeiro do plantão vai até a baia e encosta o smartphone na coleira do pet. O prontuário abre em 1 segundo com os remédios do horário.

💡 Como pagar um café encostando o celular na maquininha de cartão.
4

Alta & Reuso da Tag

Ao receber alta curado, o vínculo é desfeito no sistema. A coleira é higienizada com álcool 70% e volta para o estoque pronta para o próximo paciente.

💡 Custo de reposição zero: a mesma coleira pode ser reutilizada milhares de vezes.

Dúvidas Frequentes da Banca e Equipe

Perguntas Essenciais para Apresentação

Respostas diretas e esclarecedoras para as perguntas mais comuns em apresentações técnicas e bancas examinadoras.

🔋 A coleira precisa de bateria ou pilha?

Não! As tags NFC utilizadas (chips NTAG213/215) são componentes passivos. Elas são energizadas momentaneamente pelo campo eletromagnético emitido pela antena do próprio smartphone na hora da aproximação. Duram décadas sem qualquer manutenção.

💧 E se o animal molhar a coleira com água ou urina?

Sem problemas! Os chips NFC são encapsulados em silicone médico ou resina epóxi selada (grau de proteção IP68). Podem ser lavados com água e sabão e desinfetados com álcool 70% entre internações sem perder dados.

📱 Funciona em qualquer aparelho celular?

Sim! Praticamente todos os smartphones Android modernos com suporte a NFC (via navegador Google Chrome com Web NFC API nativa) e iPhones conseguem ler as tags e abrir o prontuário instantaneamente.

🌐 Precisa digitar o prontuário na memória da coleira?

Não! A coleira armazena apenas um identificador permanente e um link (`/bedside/:codigo`). Todas as informações clínicas ficam protegidas e criptografadas no servidor em nuvem. Se a coleira for perdida, nenhum dado de saúde do animal vaza.

💻 Como testar no computador se não tenho leitor NFC?

O NFCareVet possui um Modo de Simulação Integrado. Na tela de login e no leitor, botões de simulação permitem demonstrar todas as funcionalidades mesmo em notebooks de desenvolvimento sem hardware NFC.

🎓 Qual o diferencial para o UPX (Engenharia)?

Integração completa entre hardware de radiofrequência (NFC/NDEF), desenvolvimento web moderno de alta performance (React 19, TypeScript, NestJS), banco de dados relacional (PostgreSQL) e DevOps automatizado (Docker, Nginx, CI/CD GitHub Actions).

Arquitetura de Dados em 5 Camadas (Do Silício ao Banco de Dados)

ARQUITETURA COMPLETA

1. Camada Física & Hardware

Chips de radiofrequência a 13.56 MHz.

Chip NFC: NTAG213 / NTAG215
Padrão: ISO/IEC 14443-A
Payload Físico: UID 7-byte + Bloco NDEF URI
Leitores: Sensor NFC Mobile / Leitor USB Desktop

2. Camada Cliente (Frontend SPA)

Aplicação em React 19 executando no navegador do cliente.

Engine: React 19 + TypeScript + Vite 8
Hardware Bridge: navigator.NDEFReader
Estado Global: Zustand (Session, NFC, Toasts)
Data Fetching: TanStack Query v5 (Prefetch + Cache)
Network Client: Axios com Interceptor Bearer JWT

3. Borda & Proxy Reverso

Servidor Nginx gerenciando terminação SSL e roteamento de portas.

Nginx Host: Porta 80 / 443 (Certbot Let's Encrypt)
Frontend Proxy: proxy_pass 127.0.0.1:8085
API Routing: Encaminha /api/* para backend:3000
Compressão: Gzip ativado para chunks JS/CSS

4. Aplicação Backend (NestJS 11)

Servidor RESTful corporativo modular em TypeScript.

Guards: JwtAuthGuard + RolesGuard
DTO Validation: class-validator + class-transformer
Módulos Centrais: Auth, Users, NfcTags, Bedside, Hospitalizations
Documentação: Swagger OpenAPI (/api/docs)

5. Persistência & Banco de Dados

PostgreSQL relacional com transações atômicas ACID.

Banco: PostgreSQL 16 Alpine
ORM: Prisma ORM Client
Índices: NfcTag(uid, publicCode), User(badgeUid)
Transações: prisma.$transaction para checagem clínica
